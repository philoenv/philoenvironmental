Welcome to Philo Environmental LLC Borehole Studio

Philo Environmental LLC Borehole Studio is a browser-based borehole logging tool designed to replace rigid legacy logging software with modern web flexibility.

Dual Logging Modes Seamlessly switch between Environmental (PID screening, odor/sheen, well construction) and Geotechnical (SPT blow counts, recovery %, RQD) modes with a single click.
Live In-Browser Editing Click any field to update stratigraphy descriptions, layer depths, or sample IDs in real time, with automatic depth-ruler scaling and smart stratum boundary borders.
Effortless Export & PDF Output Save and reload your project data anytime via lightweight JSON, or use Print / Export PDF to generate clean, vector-sharp print deliverables formatted for standard page layouts. No installations, plugins, or proprietary viewers required.
